How to Use VoicePilot

A comprehensive guide to hands-free web browsing.
🚀 #ElevenHacks — Build something you can use without ever touching a keyboard.

1. Installation

Since VoicePilot is a developer build, you'll need to load it manually into Google Chrome (or any Chromium-based browser):

1

Download the extension and unzip/extract the downloaded voice-pilot.zip file to a folder on your computer.

2

Open Chrome and navigate to chrome://extensions/.

3

Enable Developer mode (toggle in the top-right corner).

4

Click "Load unpacked" and select the unzipped folder from your computer.

2. Configuration

VoicePilot requires API keys to function. It uses a "bring-your-own-key" model so you only pay for what you use directly to the providers.

  • OpenAI / OpenRouter API Key (Required): Used to analyze page context and understand your commands. OpenRouter is recommended for broader model access.
  • ElevenLabs API Key (Recommended): Used to generate state-of-the-art, ultra-realistic voice responses. If not provided, it falls back to your browser's default TTS.

Click the VoicePilot icon in your Chrome toolbar, enter your keys, and click Save Settings.

3. The Voice Orb Interface

Once installed, you will see a glowing orb in the bottom-right corner of every website. The orb has 5 animated states to let you know what it's doing:

  • Idle: Subtle breathing glow. It's waiting for you to interact.
  • Listening: Pulsing rings. It is actively recording your voice.
  • Processing: Spinning hue-rotate gradient. It is thinking and querying the AI.
  • Speaking: Animated waveform bars. It is talking back to you.
  • Error: Red pulse. Something went wrong (e.g. invalid API key).

4. Navigating Without a Keyboard

Click the orb and speak naturally to navigate the web. Here are some commands you can try:

🧭 Navigation Commands

  • "Scroll down" / "Scroll to top"
  • "Find pricing" (Automatically scrolls to the pricing section)
  • "Go to contact"
  • "Go back" / "Go forward"

🖱️ Interaction Commands

  • "Click Get Started" (Finds the button and clicks it)
  • "Press Sign Up"
  • "Click Contact Sales"

🧠 Page Understanding

  • "What is this website?" (Summarizes the current page)
  • "Describe this page" (Reads the layout and content)
  • "What does this company do?"

📝 Form Filling

  • "Type John Doe in the name field"
  • "Fill the email field with example@email.com"
  • "Submit form"

5. Conversational Memory

VoicePilot remembers the context of your conversation. You don't have to repeat yourself!

You: "Find pricing."
VoicePilot navigates to the pricing section.

You: "Which plan is best for startups?"
VoicePilot analyzes the pricing table and recommends a plan aloud.

You: "Compare it with the enterprise plan."
VoicePilot compares the two plans based on the page content.

The conversation history resets when you switch tabs, keeping your experience clean and focused on the active page.
