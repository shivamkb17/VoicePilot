# Affiliate Disclosure (VoicePilot)

Last updated: 2026-05-09

VoicePilot may include signup links to third-party AI providers with affiliate parameters.

## What this means

- If a user signs up through an affiliate link, the VoicePilot developer may earn a commission.
- This helps support development and operating costs.

## Important clarifications

- Users are not required to use affiliate links.
- Users can use their own existing provider accounts and keys.
- Affiliate relationships do not grant the developer special access to user prompts, page content, or API account data.
- Runtime data handling is governed by `PRIVACY_POLICY.md` and provider policies.

## Transparency commitment

Where affiliate links are shown, VoicePilot aims to label them clearly as affiliate links.
